# 브랜딩 모듈

## 책임

브랜딩 모듈은 제품명, 태그라인, 업무 유형 라벨, 로고와 앱 아이콘의 톤을 한곳에서 관리합니다.

## 설계 사상

브랜드 문구는 UI 코드 곳곳에 흩어지면 이후 수정이 어려워집니다. 사용자가 지속적인 부분 수정을 원했으므로, 이름과 문구는 별도 모듈에 모아 변경 비용을 낮춥니다.

## 현재 규칙

- 제품명은 `Pineflow`입니다.
- 현재 태그라인은 `나만의 리듬으로 남기는 출퇴근`입니다.
- 업무 유형은 회사 부서나 직책이 아니라 개인 활동의 의도를 기준으로 둡니다.
- 업무 유형에는 짧은 설명 문구와 자주 쓰는 메모 후보가 따라붙습니다. 이 문구는 사용자가 모드의 의미를 기억하지 않아도 고를 수 있게 돕는 UX 장치입니다.
- 로고는 `Pineflow Mark`입니다. 파인애플의 잎과 둥근 몸체를 유지하되, 얼굴/귀/발 대신 흐름 리본을 넣어 시간 기록과 하루 흐름을 표현합니다.
- 귀여움은 캐릭터 표정이 아니라 통통한 비율, 둥근 실루엣, 부드러운 곡선에서만 남깁니다.
- 앱 아이콘은 같은 Pineflow Mark를 밝은 뉴트럴 배경 위에 배치해 검은 다이아몬드 몸통과 초록 리본이 작은 크기에서도 흐려지지 않게 합니다.
- 2026-05-25 기준 서비스 로고는 `v21 A. Wide Underpass` 방향을 반영합니다. 리본은 밝은 초록 계열을 쓰고, 파인애플 머리 영역은 통째로 비워 리본이 뒤로 지나가는 구조를 명확히 합니다.
- 헤더처럼 작은 공간에서는 리서치 시안 원본을 그대로 축소하지 않고 compact mark로 단순화합니다. 리본은 얇게, 다이아몬드 몸통은 크게 배치해 작은 카드 안에서도 파인애플과 흐름이 분리되어 보여야 합니다.
- 몸통은 다이아몬드 격자만 사용합니다. 중앙 컬러 강조는 쓰지 않고, 우측 흐름 방향의 다이아몬드에만 작은 초록 포인트를 둡니다.
- 색상은 뉴트럴 표면, 파인 그린 CTA/진행, 작은 파인애플 골드 강조로 역할을 분리합니다. 코랄/빨강은 오류나 위험, 파랑은 정보성 상태에만 씁니다.

## 향후 문서화할 변경

- 최종 한국어 서비스명 변형.
- 알림과 온보딩 문구의 톤앤매너.
