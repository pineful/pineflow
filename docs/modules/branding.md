# 브랜딩 모듈

## 책임

브랜딩 모듈은 제품명, 태그라인, 업무 유형 라벨, 로고와 앱 아이콘의 톤을 한곳에서 관리합니다.

## 설계 사상

브랜드 문구는 UI 코드 곳곳에 흩어지면 이후 수정이 어려워집니다. 사용자가 지속적인 부분 수정을 원했으므로, 이름과 문구는 별도 모듈에 모아 변경 비용을 낮춥니다.

## 현재 규칙

- 제품명은 `Pineflow`입니다.
- 현재 태그라인은 `나만의 리듬으로 남기는 출퇴근`입니다.
- 업무 유형은 회사 부서나 직책이 아니라 개인 활동의 의도를 기준으로 둡니다.
- 업무 유형에는 짧은 설명 문구와 빠른 의도 후보가 따라붙습니다. 이 문구는 사용자가 모드의 의미를 기억하지 않아도 고를 수 있게 돕는 UX 장치입니다.
- 로고는 파인애플을 기반으로 하되, 작은 동물처럼 보이는 귀, 얼굴, 볼, 발을 더해 개인 기록 서비스의 친근함을 표현합니다.
- 앱 아이콘은 동일한 캐릭터형 파인애플을 어두운 초록 배경 위에 배치해 브라우저 탭과 홈 화면에서도 Pineflow임을 알아볼 수 있게 합니다.

## 향후 문서화할 변경

- 최종 한국어 서비스명 변형.
- 알림과 온보딩 문구의 톤앤매너.
