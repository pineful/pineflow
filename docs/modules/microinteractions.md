# 마이크로인터랙션 모듈

## 책임

마이크로인터랙션 모듈은 버튼 터치, 메뉴 열림, 저장 성공처럼 작은 조작 순간에 들어가는 움직임과 효과음을 정의합니다.

## 설계 사상

Pineflow의 움직임과 소리는 기능 설명을 대신하는 장식이 아니라, 사용자가 “눌렀다”, “열렸다”, “저장됐다”를 작게 확인하는 피드백이어야 합니다. 개인 기록 서비스의 분위기에 맞게 차분하고 귀여운 감각을 주되, 업무 중 켜 두어도 방해되지 않아야 합니다.

## 현재 규칙

- 효과음은 기본값이 꺼짐입니다.
- 효과음은 계정 메뉴의 `효과음 켜기/끄기`에서 사용자가 직접 변경합니다.
- 효과음은 외부 파일을 가져오지 않고 Web Audio API의 `OscillatorNode`와 `GainNode`로 짧게 생성합니다.
- 효과음은 사용자 조작에만 반응합니다. 시간 흐름, 날씨 갱신, 토큰 점검 같은 자동 업데이트에는 재생하지 않습니다.
- 소리는 짧고 작은 볼륨으로 유지합니다. 탭, 메뉴/편집 열림, 저장 성공 정도의 구분만 둡니다.
- 움직임은 버튼 터치 축소, 메뉴/편집 패널의 짧은 등장, 흐름 그래프의 보조 애니메이션 정도로 제한합니다.
- `prefers-reduced-motion` 환경에서는 반복 애니메이션과 팝업 등장 애니메이션을 끕니다.
- 모션이나 사운드가 없더라도 같은 정보를 텍스트와 숫자로 읽을 수 있어야 합니다.

## 참고한 UX 기준

- 사용자가 원하지 않는 자동 소리는 피하고, 소리 제어권을 사용자에게 둡니다.
- 반복되거나 강한 움직임은 피하고, 업무 중 계속 열어두는 화면에 맞게 미세한 피드백만 남깁니다.
- 태블릿처럼 큰 화면에서는 그래프와 조작 영역을 분리해 시선 이동을 줄입니다.

## 향후 문서화할 변경

- 계정 설정 화면에서 효과음 종류를 선택하는 기능.
- 저장/실패/충돌 상태별 세부 사운드 패턴.
- 더 정교한 태블릿 전용 모션 또는 그래프 인터랙션.
