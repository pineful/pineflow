# 요약 모듈

## 책임

요약 모듈은 오늘의 누적 근무 시간, 첫 출근, 마지막 퇴근, 하루 목표 대비 진행률을 계산합니다.

## 설계 사상

Pineflow는 사용자가 “내 오늘이 어떻게 흘러가고 있지?”를 먼저 알 수 있어야 합니다. 요약 영역은 기본적으로 읽기 화면이며, 매번 조작해야 하는 설정 패널처럼 보이면 안 됩니다.

서비스를 켜 둔 채 일하는 상황에서는 사용자가 화면을 볼 때마다 가장 먼저 확인하는 정보가 오늘 누적 시간입니다. 따라서 누적 시간 그래프는 로그인 후 상단 패널의 첫 번째 핵심 정보로 배치합니다.

현재 대시보드 방향은 `Calm Live Board`입니다. 예쁜 장식형 대시보드보다 조용한 시간 계기판에 가깝게, 현재 상태와 오늘 누적 시간을 3초 안에 읽을 수 있어야 합니다.

2026-06-05 이후 상단 대시보드 표면은 `Quiet Telemetry Glass` 방향을 따른다. 이는 딥 그린 계기판, 얇은 경계선, 미세한 grid, 정돈된 숫자와 marker로 미래형 정밀감을 더하되, 그래프 자체는 실제 기록 기반의 읽기 정보로 유지하는 기준이다.

초기 미래형 적용에서 그래프 카드가 밝은 흰 카드로 남아 사용자가 변화를 거의 느끼지 못한 문제가 있었다. 따라서 상단 `Calm Live Board`는 첫 화면의 핵심 면적답게 어두운 telemetry board여야 하며, 그래프 canvas, 축, 현재점, 목표선, 하단 insight까지 모두 같은 계기판 안의 데이터로 보여야 한다. 작은 배경선이나 버튼만 바뀐 상태는 이 모듈의 디자인 기준을 충족하지 않는다.

## 현재 규칙

- 사용자의 현재 로컬 날짜와 같은 날의 기록만 오늘 요약에 포함합니다.
- 짝이 맞는 출근/퇴근 기록은 완료된 시간으로 계산합니다.
- 활성 세션은 퇴근 전까지 현재 시각 기준으로 누적 시간에 반영합니다.
- 누적 시간은 단순 막대보다 `시간이 흐르고 있다`는 감각이 드러나는 그래프형 카드로 보여줍니다. 현재 상태, 현재 누적 시간, 목표까지 남은 시간, 목표 대비 진행률, 이번 세션 경과를 같은 카드 안에서 읽게 합니다.
- 그래프는 추상 장식 곡선이 아니라 오늘 기록을 기반으로 한 누적 면적 그래프입니다. 가로축은 하루 시간대, 누적선은 실제 출근/퇴근 기록과 활성 세션을 반영합니다.
- 그래프 안에는 현재 시각선, 목표선, 출근/퇴근 기록점, 활성 세션 현재점이 들어갑니다.
- 모바일에서는 이 그래프가 상단 패널에서 시계와 기록 입력보다 먼저 보입니다.
- 태블릿 이상에서는 상단 패널을 가로형 대시보드로 바꾸고, 왼쪽의 큰 그래프와 오른쪽의 시계/기록 입력/출퇴근 CTA가 한 화면에 함께 들어오도록 합니다.
- 상단 히어로 그래프는 로고와 가까이 붙어 있으므로 카드 상단 장식선을 쓰지 않습니다. 로고 아래의 선이나 얼룩처럼 읽히는 장식은 브랜드 요소와 혼동되므로 제거합니다.
- 좌측 사이드바, 큰 배경 패턴, 과한 마스코트 장식은 첫 화면에 넣지 않습니다. 최근 기록과 날씨는 보조 정보이며, 상단 그래프보다 강하게 보여서는 안 됩니다.
- 최근 기록과 날씨가 보조 정보라고 해서 기존 흰 카드로 남겨 두면 안 됩니다. 첫 화면 전체는 같은 telemetry glass 계열로 읽히되, 상단 보드의 위계가 가장 강해야 합니다.
- 그래프는 사용자가 켜 둔 채 보는 정보이므로 기본 상태에서 정지 화면이어야 합니다. sweep, pulse, line draw 같은 자동 반복/등장 애니메이션은 쓰지 않습니다.
- Dribbble식 미래형 UI를 참고하더라도 상단 그래프는 사이버보안/항공 HUD처럼 긴장감을 주면 안 됩니다. Pineflow의 미래감은 장식적 조준선이 아니라 시간 기록을 안정적으로 읽는 계기판 표면에서 나와야 합니다.
- 움직임은 정보의 보조 표현이어야 하며, 버튼 눌림, 메뉴 열림, 저장 toast 같은 사용자 조작 피드백에만 짧게 둡니다. `prefers-reduced-motion` 환경에서는 남은 애니메이션도 끕니다.
- 하루 목표 시간은 분 단위로 저장하며 30분 단위로 변경할 수 있습니다.
- 시간 표기는 자연어 읽기 중심입니다. `1시간 7분`처럼 분 앞에 0을 붙이지 않습니다.
- 목표 시간은 기본적으로 `하루 목표`와 `목표 대비 진행률`로 표시하고, 슬라이더는 `목표 수정`을 눌렀을 때만 보여줍니다.
- 목표 슬라이더를 움직일 때마다 API를 호출하지 않습니다. 사용자가 새 목표를 확인한 뒤 `저장`을 누를 때 한 번만 저장합니다.

## 향후 문서화할 변경

- 주간 요약.
- 야간 근무자를 위한 하루 경계 설정.
- 휴식 시간 추적.
- 통계 차트와 내보내기.
