# Pineflow 동적 비대칭 곡선 시안 v10

마지막 업데이트: 2026-05-25

## 목적

사용자가 `B` 스타일을 더 마음에 들어 하되, 곡선의 형태, 색, 질감이 충분히 개발되지 않았고 다이아몬드 몸통 간격이 불규칙하다고 지적했다. 이 문서는 그 피드백을 반영한 v10 시안의 기준과 결과를 기록한다.

## 반영한 피드백

- 곡선은 `B` 방향처럼 비대칭 열린 곡선을 유지한다.
- 곡선 시작부터 끝까지 더 역동적인 흐름이 보여야 한다.
- 색은 단순 초록 선이 아니라 시작, 진행, 종료의 흐름을 가져야 한다.
- 질감은 장식이 아니라 속도감과 진행감을 보강해야 한다.
- 파인애플 몸통은 다이아몬드 간격을 균일하게 다시 설계한다.

## 개선 내용

- 몸통을 `1-2-3-2-1` 다이아몬드 격자로 재구성했다.
- 각 다이아몬드의 x/y 간격을 일정한 리듬으로 맞췄다.
- 몸통은 여전히 면으로 채우지 않고 다이아몬드-only 구조를 유지한다.
- 곡선에는 시작점, 진행 하이라이트, 종료 마커를 분리해 부여했다.
- 곡선 색은 민트에서 딥 그린을 거쳐 골드로 이동하도록 구성했다.

## 후보

### A. Dynamic Offset Sweep

가장 추천하는 방향이다. `B`의 비대칭 열린 곡선 방향을 유지하면서도 더 역동적이다. 시작점에서 출발해 잎 위쪽을 지나 종료 마커로 끝나는 흐름이 읽힌다.

### B. Momentum Graph Arc

대시보드 진행 그래프와 더 직접적으로 연결되는 방향이다. A보다 기술적이고 차트 느낌이 강하지만, 브랜드 마크 자체의 부드러움은 A보다 약하다.

## 현재 판단

현재는 `A. Dynamic Offset Sweep`을 우선 후보로 본다. 다음 단계에서 실제 서비스에 반영하려면 SVG를 서비스용 로고 컴포넌트와 favicon/app icon 크기에 맞게 정리해야 한다.
