# 대시보드 UX 재설계 리서치

날짜: 2026-05-24

## 목적

Pineflow의 첫 화면이 단순한 기록 화면이 아니라, 켜 둔 채 볼 수 있는 개인 시간 계기판처럼 느껴지도록 대시보드 구조를 재설계한다.

## 조사 기준

- 시간 추적 앱은 현재 타이머와 오늘 누적 시간이 가장 먼저 읽혀야 한다.
- 생산성 앱은 정보가 많아질수록 대시보드가 무거워지므로 모바일 첫 화면에서는 핵심 지표 3-4개로 제한한다.
- 감성형 집중 앱의 성장/보상 은유는 매력적이지만 Pineflow에서는 과하면 유치하거나 피로해진다.
- 진행 중 활동은 glanceable해야 하며, 사운드와 모션은 사용자 조작에 대한 보조 피드백이어야 한다.

참고한 공개 자료:

- Toggl Track 모바일 타이머와 리포트 패턴.
- RescueTime dashboard의 오늘 기록, 목표, 하이라이트 구조.
- Apple Live Activities의 진행 중 활동 glanceability 원칙.
- Material motion/sound의 짧고 목적 있는 피드백 원칙.
- W3C WCAG의 자동 움직임/소리 제어 원칙.
- Atlassian, Material, Carbon, Tableau의 색상 역할 분리와 데이터 시각화 색상 원칙.
- Google Trends는 절대 수요가 아니라 상대 관심도 지표로만 참고.

## 최종 방향

첫 화면 이름은 `Calm Live Board`로 둔다.

Pineflow는 예쁜 카드 모음이 아니라 조용한 시간 계기판이어야 한다. 사용자는 3초 안에 현재 상태, 오늘 누적 시간, 목표까지 남은 시간, 이번 세션 경과를 읽을 수 있어야 한다.

## 구현 원칙

- 상단 그래프는 추상 장식 곡선이 아니라 실제 오늘 기록 기반 누적 면적 그래프여야 한다.
- 그래프에는 하루 시간대 축, 현재 시각선, 목표선, 출근/퇴근 기록점, 활성 세션 현재점을 둔다.
- 모바일에서는 그래프가 시계와 기록 입력보다 먼저 온다.
- 태블릿 가로에서는 그래프가 왼쪽 60-65%, 시계/세션/CTA가 오른쪽 35-40%에 배치된다.
- 최근 기록은 그래프/CTA 바로 아래에 둔다.
- 날씨와 목표 설정은 보조 정보이며 상단 그래프보다 강한 시각 위계를 갖지 않는다.
- 좌측 사이드바, 큰 배경 패턴, 반복 마스코트, 장식용 blob은 사용하지 않는다.
- 그래프는 기본적으로 정지 화면이어야 한다. 자동 sweep, pulse, line draw, board reveal처럼 계속 시선을 끄는 움직임은 사용하지 않는다.
- 모션은 버튼 눌림, 메뉴 열림, 저장 toast처럼 사용자가 직접 조작한 순간에만 200ms 이하로 제한한다.
- 사운드는 opt-in이며 출근, 퇴근, 저장, 메뉴/편집 열림, 탭 선택 같은 사용자 조작에만 반응한다.
- 색상은 중립 배경과 표면을 기본으로 하고, 파인 그린은 CTA/핵심 진행, 골드는 로고와 목표선 같은 작은 강조, 파랑/빨강은 정보/위험 상태에만 쓴다.
- 로고는 동물형 캐릭터보다 `잎 + 둥근 파인 실루엣 + 흐름 리본`으로 구성한 Pineflow Mark를 기본 방향으로 한다.

## 피해야 할 방향

- 팀/청구/프로젝트 관리 앱처럼 표와 리포트를 상단에 올리는 방향.
- 게임형 집중 앱처럼 보상과 캐릭터를 첫 화면의 주인공으로 만드는 방향.
- 단순 원형 게이지나 추상 곡선만으로 실제 시간 흐름을 숨기는 방향.
- 사운드 자동 재생, 반복되는 축하 애니메이션, 백그라운드 갱신 사운드.
- 그래프 내부의 무한 shimmer, breathing, pulse, 선 그리기 반복.
- 카드마다 임의의 민트, 하늘색, 코랄을 섞어 색상 역할을 흐리는 방향.

## 2026-05-24 추가 비판 검토

분야별 검토 결론은 다음과 같다.

- 모션/접근성: 상단 그래프는 켜 둔 채 보는 정보이므로 정지 화면이어야 한다. `prefers-reduced-motion`은 보조 안전망이고, 기본 상태부터 반복 모션을 쓰지 않는 것이 원칙이다.
- 색채: Pineflow는 과일색을 화면 전체에 넓게 쓰면 유치해진다. 차분한 뉴트럴 UI, 깊은 파인 그린 CTA, 작은 파인애플 골드 포인트로 정리한다.
- IA: 모바일은 `Calm Live Board -> 기록 조작 -> 최근 기록 -> 보조 날씨/요약` 순서를 유지한다. 태블릿은 그래프와 조작 영역이 같은 시야 안에 들어오는 2열 구조가 맞다.
- 로고: 얼굴, 귀, 발을 가진 마스코트형 파인애플은 첫 인상은 귀엽지만 장기 브랜드 마크로는 약하다. 앱 아이콘에서도 읽히는 면 기반 Pineflow Mark로 바꾼다.
- 사운드: 효과음은 기본 꺼짐, 사용자 조작에만 짧게 재생한다. 그래프나 시간 흐름에 사운드를 묶지 않는다.
